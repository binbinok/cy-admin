# 数据库索引创建指南

## 概述

为提升查询性能，需为以下集合创建索引。

## 自动创建（推荐）

部署 `initDatabaseIndexes` 云函数后，调用该函数自动创建所有索引：

```bash
# 使用 CloudBase CLI 调用
npx @cloudbase/cli@latest fn invoke --name initDatabaseIndexes --envId cloud1-1g7yz5w766dd366f
```

或在登录后的管理后台页面触发一次调用。

## 手动创建（CloudBase 控制台）

### 步骤

1. 登录 [CloudBase 控制台](https://tcb.cloud.tencent.com)
2. 选择环境 `cloud1-1g7yz5w766dd366f`
3. 进入「数据库」→「文档型数据库」
4. 选择对应集合，点击「索引管理」
5. 点击「新建索引」

### 需要创建的索引

#### 1. consumption_records 集合

**索引 1：技师业绩查询**
```json
{
  "technicianId": 1,
  "createdAt": -1
}
```
- 用途：技师业绩统计和明细查询
- 字段说明：技师ID升序，创建时间降序

**索引 2：支付方式分类统计**
```json
{
  "paymentDetails.paymentType": 1
}
```
- 用途：按支付方式（现金/会员卡/美团）分类统计收入

#### 2. appointments 集合

**索引：时间冲突校验**
```json
{
  "technicianId": 1,
  "appointmentDate": 1
}
```
- 用途：预约创建时校验技师时间冲突

#### 3. members 集合

**索引：手机号唯一性**
```json
{
  "phone": 1
}
```
- 属性：Unique（唯一索引）
- 用途：确保手机号不重复，加速手机号查询

#### 4. operation_logs 集合

**索引：操作日志查询**
```json
{
  "adminId": 1,
  "createdAt": -1
}
```
- 用途：按管理员查询操作日志

## 索引创建后的验证

创建完成后，可在控制台「索引管理」页面查看所有索引状态。

## 性能影响

- **查询性能**：索引创建后，相关查询速度提升 10-100 倍
- **写入性能**：轻微影响（每次写入需更新索引）
- **存储空间**：索引会占用额外存储空间，约为数据的 10-20%

## 注意事项

1. **生产环境**：建议在低峰期创建索引
2. **大集合**：现有数据量大的集合创建索引可能需要几分钟
3. **唯一索引**：members.phone 的唯一索引要求现有数据无重复，否则创建失败
4. **重复运行**：`initDatabaseIndexes` 云函数可重复调用，已存在的索引会被跳过

## 故障排除

### 索引创建失败
- 检查是否有重复数据（特别是唯一索引）
- 检查字段类型是否一致
- 查看 CloudBase 控制台错误日志

### 查询仍然慢
- 确认查询条件使用了索引字段
- 检查复合索引的字段顺序是否符合查询模式
- 考虑添加覆盖索引（包含查询返回的所有字段）
