# Change: 新增预约创建、收入录入增强与工资条导出

## Why

当前管理端缺少以下关键能力：
1. 预约管理仅有查看和处理能力，管理员无法在后台直接创建新预约
2. 会员创建流程缺少弹窗交互规范和会员卡关联字段
3. 收入录入缺少多支付方式支持（会员卡/现金/美团混合支付）
4. 财务模块缺少技师工资条导出能力
5. 技师业绩统计缺少业务记录明细查看能力

这些缺口导致日常运营流程需要借助外部工具或人工记录，增加了管理成本和出错概率。

## What Changes

### 会员管理
- 在会员列表页添加"新增会员"按钮
- 点击后弹出新增会员弹窗，可录入：
  - 会员昵称（2–20 字符）
  - 会员手机号（符合 `1[3-9]\d{9}` 格式）
  - 会员生日（YYYY-MM-DD 格式，日期选择器）
  - 会员卡信息（选择框，下拉选择会员卡管理中的可用会员卡）

### 预约订单
- 在预约列表页添加"新增预约"按钮
- 点击后弹出预约表单弹窗，可录入：
  - 指定技师（选择框，下拉选择技师管理中的在职技师）
  - 服务项目（选择框，下拉选择服务项目中的上架服务）
  - 预约时间（日期时间选择器，YYYY-MM-DD HH:mm 格式）
  - 备注（文本输入框）
- 提交时校验预约时间与技师已有预约是否冲突
- 冲突时返回错误提示："该时间段技师已被预约"

### 财务统计 - 收入录入增强
- 添加"金额类型"选项（选择框）：
  - 下拉选项：[会员卡, 现金, 美团]
  - 每种金额类型对应一个费用金额
  - 已选择的金额类型在全局下拉选项中标记为 disabled（不可重复选择）
  - 支持一笔收入使用多种支付方式（如会员卡 + 现金）
- "服务费用"与"金额类型"为一组：
  - 支持添加、删除费用组
  - 费用组数量大于 1 条时可删除对应组
  - 费用组数量等于 1 条时不可删除
  - 最大数量为金额类型选项的总长度（即最多 3 组）
- 提交时校验各组费用金额必须大于 0

### 财务统计 - 技师业绩明细
- 在技师业绩统计页面，支持查看指定技师的业务记录明细
- 点击技师名称或"查看明细"按钮后，展示该技师的所有收入记录列表
- 每条收入记录展示：
  - 服务时间
  - 服务项目
  - 金额类型（会员卡/现金/美团）
  - 费用金额
  - 客户信息
  - 备注

### 财务统计 - 导出工资条
- 添加"导出工资条"按钮
- 点击后弹出导出表单弹窗：
  - 姓名（选择框，下拉选择技师管理中的在职技师）
  - 月份（日期选择器，YYYY-MM 格式）
- 导出格式：CSV（实现成本更低）
- 导出内容包含：
  - 技师姓名
  - 统计月份
  - 完成订单数
  - 服务总金额
  - 应得提成金额

## Impact

- Affected specs: `admin-system`
- Affected code:
  - 前端页面：`src/pages/member/MemberListPage.tsx`、`src/pages/appointment/AppointmentListPage.tsx`、`src/pages/finance/FinancePage.tsx`
  - 服务层：`src/services/member.ts`、`src/services/appointment.ts`、`src/services/finance.ts`、`src/services/technician.ts`
  - 云函数：新增/扩展预约创建、收入录入（多支付方式）、工资条数据查询、技师业绩明细查询接口
  - 数据模型：`appointments`（新增预约创建）、`consumption_records`（扩展收入明细）、`technician_performance`（新增工资条数据聚合）
- Breaking change: 无
