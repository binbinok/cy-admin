# 新增：预约看板（技师时间线视图）

## Why

预约列表以表格形式呈现，管理员无法直观看到某天各位技师的空闲与占用情况，排班与接单决策需要心算时间冲突。需要一个按「技师 × 时间轴」的可视化看板。

已与用户确认的决策：

- 采用**与预约列表同页的双视图切换**（Segmented「列表视图 / 看板视图」），不做独立页面——操作闭环（看板发现空闲可新增、点预约块可确认到店/完成服务）在同一页完成；
- 时间轴按 30 分钟刻度渲染，预约块按实际起止时间精确渲染；
- 默认展示当天，可左右切日；时间范围从当天技师排班推导（最早开始～最晚结束），无排班时兜底 10:00–22:00；
- 第一版交互：只读展示 + 点击预约块弹出操作（确认到店 / 完成服务 / 取消预约）；「点空闲区域快速新增预约」放二期；
- 状态颜色沿用现有约定（待服务橙 / 服务中蓝 / 已完成绿），已取消默认隐藏，可开关显示。

## What Changes

### 预约列表页双视图

- 页面顶部增加「列表视图 / 看板视图」切换；技师筛选条件两个视图共享。

### 看板组件 `src/components/appointment/ScheduleBoard.tsx`

- 布局：首列时间轴（30 分钟刻度），其后每位列一个技师（受技师筛选条件过滤）。
- 数据：看板通过 React Query 自取数据（`adminGetAppointmentList` 按单日查询、`adminGetTechnicianList` 复用 `['settlementOptions', 'technicians']` 缓存）。
- 渲染：技师当天排班时段以浅色背景块显示；预约块按 `appointmentTime` 与 `duration`（缺省 60 分钟）绝对定位，显示时间、客户姓名、服务大类，颜色按状态。
- 交互：点击预约块弹出操作气泡（待服务→确认到店；服务中→完成服务，复用现有 `IncomeEntryModal` 链路；均可取消预约）；操作成功后刷新看板数据。
- 已取消预约默认隐藏，提供「显示已取消」开关（灰色淡显）。

### 工具函数 `src/utils/schedule.ts`

- 纯函数：时间字符串转分钟数、看板时间范围推导（排班推导 + 兜底）、预约块定位计算（top/height）；供组件与测试复用。

## Impact

- 受影响规格：`appointment`（新增看板视图需求）
- 前端：新增 `src/components/appointment/ScheduleBoard.tsx`、`src/utils/schedule.ts`；修改 `src/pages/appointment/AppointmentListPage.tsx`
- 云函数：零改动（复用现有查询接口）
- 数据：零改动
- 测试：时间范围推导与定位计算的单元/属性测试
