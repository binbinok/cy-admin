# 技师离职状态与离职员工展示控制

## Why

系统技师状态仅有 空闲/服务中/休息 三种，没有「离职」概念。历史数据导入后为承接离职技师的业绩，以「小佳（离职）」命名 + 休息状态变通，导致：

- 财务统计-技师业绩表、提成核算报表中离职员工与在职员工混在一起展示，干扰在职员工的查看
- 预约表单、收入录入、预约看板的技师下拉不过滤状态，离职技师仍可被新预约，存在误操作隐患
- 「休息」与「离职」语义混用，无法区分

## What Changes

- 技师状态新增 `resigned`（离职）：类型定义、状态标签、`adminUpdateTechnicianStatus` 校验放开（沿用「休息」的未完成预约拦截规则）
- 技师管理页新增「设为离职」操作（二次确认），并增加状态筛选以支持找回离职技师恢复状态
- 财务统计-技师业绩表、提成核算报表新增「显示离职员工」勾选框，默认不勾（隐藏离职技师行）
- 预约表单、收入录入弹窗、预约看板的技师选项直接排除离职技师
- 存量数据迁移：技师「小佳（离职）」状态置为 `resigned`（通过本地签发 JWT 调云函数完成）

## 影响范围

- 云函数：`adminUpdateTechnicianStatus`（状态枚举 + 拦截规则）
- 前端：`src/types/technician.ts`、`TechnicianListPage`、`FinancePage`（业绩表）、`CommissionPage`（提成报表）、`AppointmentListPage`、`IncomeEntryModal`、`ScheduleBoard`
- 数据：1 条技师文档状态迁移
